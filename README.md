# ChronoEarth
ChronoEarth is a execellent website to know more about the understanding of earth and its smallest details . This helps the children to understand the deeper informations of our home

A local-first, responsive guide to Earth's deep time, built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```

## What's inside

- Sixteen geological intervals with an interactive timeline.
- A searchable vault of 37 prehistoric and present-day creatures.
- A standalone eight-question quiz that generates a fresh randomized set on each run.
- Ten locally bundled specimen photographs. Other creature entries lazily use thumbnails from the corresponding Wikipedia article when available; otherwise their detail panel links to that article.

Photo credits and licenses are linked from creature details. Wikimedia Commons attribution pages are used for the bundled photographs; fallback thumbnails are sourced from Wikipedia article summaries.

The app has no backend or account system. The timeline and quiz data are local to the client.
